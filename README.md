# Aware

Example collection of shellscripts and dotfiles configuration files for Linux and macOS.

This repository includes Linux example configuration files for i3wm, Sway and Waybar. It also includes macOS examples for Amethyst and SKHD.

Read and pick what you like from my configurations and shellscripts.
